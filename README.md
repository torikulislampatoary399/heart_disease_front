# Heart Check - static frontend for Netlify

1. Open `js/config.js` and set `API_BASE_URL` to your Render backend URL (no trailing slash).
2. Deploy to Netlify (drag-and-drop or GitHub, see the chat instructions).
3. On Render, set the backend env var `CORS_ORIGINS` to your Netlify URL, e.g. https://your-site.netlify.app, and redeploy.
